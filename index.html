Brush

Spacing, scatter, jitter and follow apply to stamp brushes (Soft stamp, Chalk, Splatter, Dry bristle and imported tips). Each stroke becomes its own layer.

Layers

Opens SVG, PSD, PDF, AI, images, .mte and Office files (DOCX, PPTX, XLSX). Drop files onto the canvas. Arrow keys nudge (Shift = 10px).

Mockups

Your current canvas becomes the artwork: it is grouped into one layer and placed on the screen or print area. Press Ctrl+Z to undo; ungroup the layer to edit the artwork again.

Video and Office modules

Each module is its own HTML file. Enter your GitHub repo link and the files load from the repo's GitHub Pages site (https://you.github.io/repo/office.html), so Pages must be enabled for that repo. Leave it blank to load video.html and office.html from the same folder as this app. A full https:// address in a file box overrides everything.
