# MTE Productive Studio — handoff summary (v0.2.2)

Files: `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` (PWA, single-file app, fabric.js 5.3.1 canvas).
Rule for releases: bump `VERSION` in index.html AND `V` in sw.js together (e.g. `mte-studio-v0.0.2`).

## v0.2.2 changes (fixes; syntax-checked and name-collision-checked only, the sandbox has no CDN so fabric could not load: please test each item in the real app)
- **Layer lock was dead (root cause)**: `lkSet` was declared twice. The v0.0.10 Filters code (`lkSet(L,fin)`) is declared later in the file, and hoisting made it replace the v0.2.0 layer-lock `lkSet(list,v)`. Every lock click (row button, Lock / Unlock, Ctrl+/) therefore ran the filter function instead (it even wrote a blank `look` on the selected layers). The layer-lock function is now `lyLockSet`; Filters keep `lkSet`. A scan of all top-level function and const names found no other duplicates.
- **FX / looks / masks clipped text**: the effect canvas (`fxPaint`) was only the text box plus a 4 px margin, so script fonts (swashes, tall caps, descenders) outside the box were cut off. Text layers now get a margin of one font size (scaled) on every side, the cap is raised to 1200 px, and text is drawn without fabric's own object cache while it is rendered into that canvas (the cache is box-sized too). Cache key now includes font family and size. Very large text that would exceed 30 MP falls back to plain rendering (no clipping, but no effects).
- **Duplicate layers** (`dupLayers`): new ⧉ button on every layer row, a ⧉ Duplicate button in the layers action row, Ctrl+D and Arrange > Duplicate all use it. Copies go directly above the original, offset 20 px, named `name copy`, `name copy 2`, ... Works on several selected layers (order kept, copies selected afterwards), one undo step. Copies keep FX, masks, filters, blend, opacity, rounded shapes; `fx`, `look`, `shapePts`, `shapeCr` are deep-copied so editing the copy never changes the original. A copy of a locked layer comes out unlocked. Curves adjustment layers can be duplicated (copy stays unselectable like the original). Smart-object copies share the same `smartId`.

## v0.2.1 changes (nudge pad for touch screens; logic tested in headless Chromium with a stubbed canvas, please test in the real app)
- **Nudge pad** (`NG` block, markup after `#fab`): on touch screens (`pointer:coarse`) and in the phone layout (`max-width:800px`), a round ✥ button next to the Panel button opens a floating pad with up / down / left / right arrows. It is `display:none` everywhere else, so the PC layout is unchanged (pixel-compared at 1100, 1366 and 1920 px wide).
- Tap = move the selected layer (or selection) by the step in document pixels; hold = repeat (after 380 ms, every 55 ms). The centre button cycles the step 1 / 5 / 10 / 25 px. The title bar shows the layer's X / Y and is the drag handle for repositioning the pad; position, step and open/closed state are saved in `localStorage` (`mte-nudge`). Position resets on rotation.
- After a burst of nudges one `object:modified` is fired (350 ms debounce), so undo/redo and panel syncs behave like a real drag. Locked layers are refused with the lock message; nothing selected shows a hint. The pad and button hide while the Panel is open, and in the Video and Office workspaces. Keyboard arrow nudging on PC is unchanged.

## v0.2.0 changes (layers: lock, merge, drag to reorder; written without a test against the real fabric build, because the sandbox has no CDN access. Layout and the reorder logic were checked in headless Chromium and Node. Please test each item in the real app)
- **Lock**: `lockedLayer` flag (added to `PROPS`, so it is saved, undone and restored). Per-row lock button (🔓/🔒) between the eye and the name, plus Lock / Unlock buttons for the selection and Ctrl+/ to toggle. `lkApply()` sets fabric's lockMovement/Rotation/Scaling/Skewing flags, hides controls and disables text editing; `layers()` re-applies it after every push and after undo/redo/load, so it survives restores. A selection that contains a locked layer cannot be dragged or transformed as a whole. Also blocked on locked layers: Delete key and the row delete button (`lkDel`), arrow-key nudging, Group, Align (skips them), Cut / Via cut / Clear selection (`needEdit`), and the write tools via `actW()` (eraser, blur, bucket, masks, layer styles, shape rounding). Not blocked: the Appearance, Filters and Looks panels still change a selected locked layer, and reordering is allowed.
- **Merge** (`mergeLayers`): Merge down (Ctrl+E on one layer), Merge selected (Ctrl+E with several selected), Merge visible (Ctrl+Shift+E). Visible layers are cloned into an off-screen `fabric.StaticCanvas`, rendered with effects, masks, opacity and blend modes, trimmed with `trimCv`, and replaced by one image layer named after the lowest merged layer, placed at its position. Hidden layers are left alone. Refused with a message for locked layers or Curves adjustment layers. Resolution follows the highest `imgMul` of the layers, capped at 6000 px on the long side and 40 MP. Smart objects are rasterised.
- **Drag to reorder**: drag the ≡ handle on a row (pointer events, so mouse, pen and touch all work; the panel auto-scrolls near its edges). A gold line shows the drop position. If the dragged layer is part of a multi-selection the whole selection moves as a block. Order logic is the pure function `lyReorder()` (unit-tested). The ↑ / ↓ buttons are still there.
- Row layout is now: ≡, eye, lock, name, (mask / fx), ↑, ↓, ✕, ✎. With a mouse the rename ✎ is hidden (double-click the name instead) and row buttons are smaller so names keep some room.

## v0.1.1 changes (device compatibility; layout checked in headless Chromium at 360x740, 740x360, 915x412, 820x1180, 1366x768 with CDN libraries blocked, so please test the full app on real phones)
- **Root cause of the broken phones**: the v0.1.0 rule `body{grid-template-columns:var(--tw) 1fr var(--sw)}` came after the phone media query and overrode its single column, so phones got `84px 0 280px` and everything was squeezed into a narrow strip. Phone grid is now restored after the v0.1.0 block. Desktop (1366x768) is pixel-identical to v0.1.0.
- **Portrait phone (<= 800 px)**: two-row header (logo, version, workspace tabs, theme, menu / New, Open, Save, Save as, undo, redo, Export), bottom tool strip, Panel button and bottom sheet positioned above the strip using `--tbh` (measured height of the strip, set by a ResizeObserver), safe-area padding left/right/bottom, toast lifted above the strip.
- **Landscape phone / short touch screens**: `html.land` is set by a script in `<head>` (`(orientation:landscape) and (max-height:520px) and (pointer:coarse)`), so it applies at any width. Layout: single-row scrollable header, tools in a left column (icons only by default, group headers collapse), Panel opens as a right-hand drawer (Panel / Close button moves left of the drawer), project options row toggled by the menu button.
- **JS**: `COMPACT()` (<= 800 px or landscape phone) replaces the old `innerWidth<=800` checks for opening the panel, canvas fit padding, header options toggle and the UI module; popup menus open upward only in portrait. Fit is re-run after rotation.
- **Touch and iOS**: inputs and selects are 16 px on touch devices (stops iOS zoom on focus), `touch-action:manipulation` on buttons, overscroll locked, tap highlight off, iOS standalone meta tags added, 36 px minimum buttons on tablets.
- **Not done**: Pinch-zoom of the canvas and the centred-overflow scroll issue when zoomed in are unchanged.

## v0.1.0 changes (layout release; tested only with a stubbed browser smoke test, please test in the real app)
- **Tools grouped** (left strip): Create (Text, Shapes, Image, MTE logo, Wordmark, Social post), Select (Select, Quick Select, Obj Select), Paint & retouch (Brush, Eraser, Bucket, Blur), Vector (Curv. Pen, Border), Style & adjust (Filters, Curves, FX, Mask), Arrange (Group, Ungroup, Duplicate, Delete), View (Zoom +, Zoom -, Fit). Click a group header to collapse or expand it; the top two buttons switch **icons with names / icons only** and **collapse or expand all groups**. Icon-only mode lays the tools out in two columns so everything fits without scrolling. Each button gets a tooltip and aria-label from its name. Every button keeps its `data-t` / id, so `add[...]` handlers are unchanged (icons are CSS `::before` from `data-ic`, so click targets are still the button).
- **Side panel grouped**: Tool options (contextual: Brush, Bucket, Quick selection, Object selection, Eraser, Shape borders, Curves, Curvature pen, Blur, Layer mask; the group hides itself when none is showing), Layers, Appearance (Fill & stroke, Layer opacity, Effects & blending, Filters), Type & layout (Text, Align). Each section is an accordion (click its title; Enter/Space work). Defaults: Text, Align, Effects & blending and Filters start collapsed.
- **Panel toolbar** at the top of the side panel: *Icons* (collapse the panel to a 48 px icon rail), *Expand all*, *Collapse all*, *One at a time* (opening a section closes the others, except Tool options). In rail mode the icons open the matching section and expand the panel; a dot on the gear shows that a tool or selection has options. Modal tools (Brush, Bucket, Quick/Object Select, Eraser, Pen, Blur, Mask) expand the rail automatically; Shape borders and Curves only light the dot.
- **Auto-open**: when a tool shows its options section, that section opens by itself (MutationObserver on `hidden`). `add.looks` also opens the Filters section.
- **All devices**: state is saved per device in `localStorage['mte-ui']` (`tc` tools icons-only, `sc` side rail, `solo`, `cs` collapsed sections, `tg` collapsed tool groups, `sg` collapsed side groups). Tablet widths (801 to 1100 px) start with both rails collapsed until the user chooses; touch devices use a wider single-column icon rail. On phones (<= 800 px) the bottom tool strip shows groups as chips: tap the chip to hide or show that group, and the icons-only button shrinks the buttons; the side bottom sheet uses the same accordions (no rail on phones).
- Compact side: smaller gaps, Layers list scrolls inside its own box (32 dvh desktop, 22 dvh phone), `.row[hidden]` is now really hidden (it was overridden by `.row{display:flex}`; e.g. the CMYK row).
- Code: CSS block "v0.1.0 grouped panels" at the end of `<style>`; JS block `UI` just before `/* ===== boot ===== */`. No tool logic was changed.
- Next ideas: drag-to-resize side panel width, floating (flyout) rail panels instead of docking, drag to reorder groups, per-tool icon set (SVG) instead of text glyphs.

## v0.0.10 changes (written without a browser test)
- **Multi-select layers**: Ctrl/Cmd/Alt+click toggles, Shift+click selects a range (Ctrl+Shift adds a range), Ctrl+A selects all layers (Ctrl+A in a selection tool still selects all pixels; Ctrl+Alt+A always selects all layers), All / Invert / None buttons and a Multi-select toggle for touch. Builds a `fabric.ActiveSelection`; the layer count shows beside the buttons.
- **Paint bucket** (*Bucket* button, overlay `#ovT`): fills with the A colour from the Fill section or a pattern (dots, stripes, checker, grid, or an uploaded image tile) with scale, tolerance, contiguous or not, sample this layer or all layers, fill onto the selected layer (rasterised, grown to cover the canvas) or a new layer, opacity, 1 px edge grow, limited by a selection. Function `bucketFill`.
- **Filters / looks** (*Filters* button and side panel): Natural, Warm, Cool, Vivid, Soft, Vintage, Mono (3 shades each), Duotone (5 pairs + custom), Colour pop (red, orange, yellow, green, blue, purple), intensity slider. Stored as `o.look={id,p,amt}`; applied by `lookApply` inside the same render hook as FX and masks (so it works on any layer, not only images, is non-destructive and exports). Not inside groups. Rasterising a layer (blur/eraser/bucket) keeps the look.

## v0.0.9 changes (written without a browser test)
- **AI selection removed** (the transformers.js model failed to run for the user). `sw.js` no longer special-cases huggingface.co.

## v0.0.7 changes (written without a browser test: please test each item)
- **Mockups removed** (button, dialog and code). The v0.0.5 mockup notes below are history only; the old build can be reinstated from v0.0.6.
- **Rename layers**: double-click a layer name or tap the pencil; Enter saves, Esc cancels.
- **Eraser** (*Eraser* button): size, hardness, strength; rubs out pixels of the picked layer to transparent (non-image layers are rasterised, FX kept). Respects a selection. Shares the `#ovT` overlay with Blur/Pen/mask painting.
- **Object Selection** (*Obj Select* or Select menu): drag a box to isolate an object from its background (colour clusters from the box border vs the middle, 3 refinement passes, keeps the main blob, fills holes); click to pick a similar-coloured region (tolerance slider) for hair, clothes, eyes, sky. New / Add / Subtract. Works on the picked image layer, else the visible canvas, at up to 1000 px and returns a smooth vector outline (`SX.t==='poly'`), so every existing selection operation works on it. It is colour/edge based, not an AI model: it does not know what a person or an eye is. A real model (e.g. SAM / MediaPipe) could be plugged into `objDone`.
- **Invert selection** (Select menu, Ctrl+Shift+I, panel button) works for any selection; panel also has Isolate to new layer and Mask layer.
- **Shape borders** (*Border* button; panel appears when a shape is selected): colour, width, solid/dashed/dotted, corner join (sharp/round/bevel), no border, corner rounding. Rectangles use rx/ry; triangles and polygons become editable rounded paths (`shapePts`, `shapeCr`) and can be re-adjusted; ellipses have no corners. Edit points on a rounded path detaches it from the slider.

## v0.0.6 changes (written without a browser test: please test each item)
- **Layer Styles (FX)**: tool button *FX* (or the `fx` button on a layer row). Dialog with Blending Options, Drop Shadow, Outer Glow, Inner Shadow, Inner Glow, Stroke (outside/inside/center), Color / Gradient / Pattern Overlay, Bevel & Emboss. Stored on the layer as `o.fx`, live preview, per-effect tick to hide, *Effects visible* switch (also the dot on the layer row), *Remove all effects*, Cancel restores. Effects are drawn by one patched `fabric.Object.prototype.render` in document pixels, so they follow move/scale/rotate and export with PNG/JPG/WEBP. Limits: not inside groups; layered PDF/PSD export bakes them into the layer image (live text loses them); no Satin/Contour/Texture.
- **Layer masks** (*Mask* menu): reveal all, hide all, from selection, paint (hide/reveal brush with size, hardness, opacity), invert, switch off/on, delete. Mask is an alpha canvas in the layer's own space (max 2048 px), saved as `o.maskData`. Layer row shows a square button: tap to paint, Shift+tap to switch off. Effects follow the masked shape.
- **Curves adjustment layer** (*Curves* button): `fabric.Curves`, non-destructive, adjusts everything below it (strength = layer opacity). Panel: preset, RGB/R/G/B channel, histogram of what is below, Auto, Input/Output fields, click to add points, drag, double-click to remove. Monotone cubic curve. Covers the whole canvas; the layer is not mouse-pickable (select it in Layers).
- **Curvature Pen** (*Curv. Pen*): click to add points, path curves through them; drag to move, double-click = corner, click first point to close, Enter finishes, Esc cancels, Delete removes a point. Path or filled shape with stroke width/colour. Result is a normal path layer (Edit points works).
- **Blur tool**: modes Brush (size, hardness, strength, blur radius; stays inside a marquee selection), Whole layer, Selected area. Rasterises the layer (keeps its FX), uses native canvas blur with a JS fallback for Safari.
- Shared overlay canvas `#ovT` serves Pen, Blur and mask painting. New code sits in one block before `/* ===== boot ===== */`.
- Next ideas: apply mask (bake), Object Selection and invert selection, Satin/Contour/Texture, curves eyedroppers.

## v0.0.5 changes
- **Transparent background**: *Transparent* in New project, and a *Make background transparent* toggle in the Fill panel. PNG and WEBP keep transparency whenever the canvas background is transparent (JPG still fills white).
- **Selection tools** (Select menu): rectangular, elliptical and lasso marquee with marching ants; Copy, Copy merged, Cut, Paste, Paste in place, Layer via copy (Ctrl+J), Layer via cut (Ctrl+Shift+J), Clear (Delete). Operations act on the layer picked in the Layers panel; text and shapes are rasterised when cut or erased. Without a selection Ctrl+C/X/V copy whole layers. Pasting an image from another app works too.
- **Mockups** (Mockup button): phone, tablet, laptop, browser window, poster frame, business card, T-shirt, mug. All vector, no external files. The current canvas is grouped as one layer ("Your design"), clipped to the screen/print area and placed on the scene; undo reverts, Ungroup edits the artwork. T-shirt and mug use Multiply so white backgrounds drop out.
- **Photoshop .abr brushes**: v6-v10 files are decoded (verified: all 16 tips of `16-free-ink-brushes.abr` match a reference decoder byte for byte, names and default spacing included). v1/v2 files are handled by best-effort code that has not been tested against a real file. Tips become stamp brushes (256 px, saved on the device).
- **Video and Office are external modules**: the built-in Office editor was removed (v0.0.4 is kept in `archive/index-v0.0.4.html`). Both tabs load their own HTML file in an iframe. *Modules...* (project options row) or *Source...* on the tab sets a GitHub repo link (resolved to `https://owner.github.io/repo/<file>`; Pages must be enabled), per-module file names, or full URLs. Contract for `office.html` / `video.html`: post `{mte:'ready'}` to the parent when loaded; the parent then sends `{mte:'open',name,bytes}` for files opened in the Studio (Office files such as docx, pptx, xlsx are routed to the Office module). `lo.html` / `lo-thread.js` (LibreOffice WASM host) are unchanged and can be reused by `office.html`.

## Done in v0.0.1
- Renamed to **MTE Productive Studio**; new logo (icon.svg + header); version badge `v0.0.1`.
- **Editable SVG**: import splits SVG into individual layers (paths, shapes, text -> editable text boxes). "Edit points" drags path anchors/curve handles; "To path" converts rect/triangle/ellipse; "SVG code" window views/edits/re-applies markup. Export SVG keeps live text and real units (mm/in/cm).

- Mobile: compact top bar, collapsible options, bottom tool strip, Panel bottom-sheet, dvh + safe areas.
- Text align left/centre/right/justify. Object align left/centre/right/top/middle/bottom (to canvas or selection).
- Effects: 16 blend modes, "Blend on white" (Multiply), "Blend on black" (Screen), Blend-If knock-out white/black with level + softness (images), clipping masks (clip to layer below / release).
- Arrow-key nudge (Shift = 10 px), Ctrl+D duplicate.
- Canvas size: presets (social, A3-A6, Letter/Legal, call/business card, sticker, barcode label, web) + custom W/H with px/in/mm/cm and DPI; works for New project and for resizing.

- **New project in a new tab** (`?p=<id>` isolated autosave per tab).
- RGB / CMYK document mode: CMYK inputs per fill, vector colours exported as DeviceCMYK. No ICC profile; images stay RGB.

- **PDF/AI**: layered export (PDF optional-content layers, live base-14 text, blend/opacity, embedded editable project for lossless round-trip). Import: embedded project > PDF layers (one editable layer each) > vector (best effort) > flat. AI export is PDF-compatible.

## Known limits / next steps (not verified in a real browser yet)
0. PDF/AI import brings in one chosen page at a time; multi-page projects are not implemented.
1. All browser features need a first test pass (written without a browser; PDF writer verified with qpdf/pypdf only).
2. PSD: shape layers, masks, clipping flags arrive as pixels; smart-object data is lost on reload; CMYK PSD not written.
3. AI: only PDF-compatible files; native Illustrator vectors are not parsed.
4. Real LibreOffice integration (bridge page + cross-origin isolation) is the next Office milestone.
5. CMYK needs ICC conversion for true print accuracy.
